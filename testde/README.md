# Bài thi kết thúc môn Lập trình Python – Mã đề 11301

Thư mục gồm 5 chương trình độc lập theo 5 câu trong đề thi. Mỗi câu nằm trong một file riêng và có thể chạy trực tiếp.

## Cách chạy

Mở Terminal tại thư mục `testde`, sau đó chạy từng lệnh:

```bash
python cau1.py
python cau2.py
python cau3.py
python cau4.py
python cau5.py
```

Nếu máy dùng lệnh `python3`, thay `python` bằng `python3`.

## Danh sách bài

- `cau1.py`: Kiểm tra n, đếm chữ số lẻ và tính tổng S.
- `cau2.py`: Đếm chữ hoa, kiểm tra chuỗi đối xứng và tính tổng chữ số.
- `cau3.py`: Nhập danh sách đến khi gặp 0, tính tổng số chẵn dương và đếm số lần xuất hiện của k.
- `cau4.py`: Quản lý thông tin sách bằng dictionary và xóa sách theo mã.
- `cau5.py`: Xây dựng lớp DienThoai và hiển thị hai đối tượng mẫu.

Mỗi file có hàm `main()` riêng, không cần cài thêm thư viện.
